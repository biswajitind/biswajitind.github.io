About BehindGit

BehindGit helps you inspect what happens behind the scenes of a Git repository through simple, focused workflows. Explore curated sequences of Git commands and see how they relate to common version control tasks.

What you can do

  • Browse opinionated Git workflows
  • Jump into steps of each workflow
  • Review commands and context for learning

Getting started

  1. Select a workflow from the left panel
  2. Open step 1 to begin
  3. Navigate across steps as needed
